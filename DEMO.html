Sincronización

Las dos vistas están conectadas. Cuando un cliente agenda, aparece al instante en tu panel.

🚀 Instalación en 3 pasos

1

Asegúrate de tener Node.js instalado (descargar)

2

Abre la terminal en la carpeta del proyecto y ejecuta:

npm install
3

Inicia la aplicación:

npm run dev

🌐 URLs después de iniciar:

Inicio: http://localhost:3000/

Cliente: http://localhost:3000/cliente

Admin: http://localhost:3000/admin

💡 Tip: Abre las dos URLs en pestañas diferentes para ver la sincronización en tiempo real
